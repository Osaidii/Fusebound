# Fusebound
This is my Fifth Published Game, A Simple Couch Tag Game!  
Free to PLAY!  
You can download this game here or from my itch.io page [osaidii.itch.io](https://osaidii.itch.io)   
This game is pretty fun to play with friends.  
  
Controls:  
WASD - Player 1  
Arrow Keys - Player 2  
TFGH - Player 3  
IJKL - Player 4  
Symbols - Player 5  
8456 - Player 6  
  
These are the source files of this game are present too!   
These files are meant to be used in Godot Engine!
